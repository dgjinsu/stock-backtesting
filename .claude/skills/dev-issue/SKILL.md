# 이슈 발행

요청: $ARGUMENTS

1. **초안**: planner 에이전트에게 요청을 넘겨 이슈 초안을 받는다. 쪼개라고 하면 여러 개를 받는다.
2. **검토**: 초안이 `docs/5_개발계획.md`의 그 단계와 맞는지, 이미 있는 이슈와 겹치지 않는지 본다. planner가 "확인할 것"을 냈으면 이슈를 만들기 전에 사용자에게 묻는다.
3. **발행**: 이슈마다 본문을 스크래치 디렉터리의 임시 파일에 쓰고 실행한다.
   ```bash
   gh issue create --title "<제목>" --body-file <파일> --label "type:<..>" --label "area:<..>" --milestone "<v1|v2>"
   ```
   출력된 이슈 주소에서 번호를 얻는다. 쪼갠 이슈는 순서대로 만들고, 뒤 이슈 본문의 배경에 "먼저: #<앞 번호>"를 적는다.
4. **현황판**: `.claude/skills/dev-board/SKILL.md`의 "이슈를 만들었을 때"대로 기록한다.
5. **알림**: 만든 이슈의 번호·제목·주소를 한 줄씩 알리고, 다음 할 일로 `/dev-start <번호>`를 적는다.

# 기능 명세서

## 무엇을 만드나

"지난 5년간 QLD를 매달 200만원씩 샀다면 지금 평단가는 얼마일까?" 같은 질문에 바로 답해 주는 웹 화면이다.
종목, 기간, 주기(매일·매주·매월), 금액을 고르면 평단가, 수익률, 평가금과 그래프를 보여 준다.

- 쓰는 사람: 나 (개인 토이 프로젝트). 나중에 공개할 수도 있게 만든다.
- 쓰는 곳: **PC 웹 브라우저만**. 휴대폰 전용 화면은 만들지 않는다 (2026-11-24 결정).
- 데이터: Yahoo Finance 일별 종가 (무료, 비공식). 자세한 건 [상세 설계](4_상세설계.md) 1절.
- 화면 시안: [Design 캔버스](https://claude.ai/artifact/Nvxz1FH9bYPKwinAibsZmr) (비공개). "v1" 페이지와 "v2" 페이지로 나눠 두었다. 시안의 숫자는 `tests/fixtures`로 실제 계산한 값이다.

## 범위

| 구분 | 내용 |
|---|---|
| v1 (먼저 만든다) | F-01 ~ F-10. 결과는 한 페이지에 모두 보여 준다 |
| v2 (v1 다음에 만든다) | F-11 ~ F-23 (F-18은 결정 d37, F-19는 결정 d36으로 제외). 결과를 탭(요약·분석·전략 비교·매수 내역)으로 나누고 분석·전략·저장·세금 같은 기능을 더한다 |
| v2 이후 후보 (화면 없음) | 비율로 나누기와 리밸런싱(포트폴리오), 물가 반영, 한국 종목 한글 이름 검색, MCP 서버, 세금을 뗀 배당 재투자 ([확장 아이디어](6_확장아이디어.md)) |
| 안 한다 | 실제 매매, 종목 추천, 주가 예측, 실시간 시세, 로그인, 휴대폰 전용 화면 |

## 정해 둔 것 (2026-11-24)

| 항목 | 결정 |
|---|---|
| 손익 색 | 미국식. 이익은 초록과 +, 손실은 빨강과 −. 색만으로 구분하지 않게 기호를 꼭 붙인다 |
| 화면 | 데스크톱 웹만. 1280px 폭 기준으로 그리고, 1024px까지는 가로 스크롤 없이 보인다 |
| 새 기능 | 시안 v2에서 늘어난 기능은 모두 v2로 둔다. v1 범위는 처음 정한 F-01 ~ F-10 그대로 |

## 화면 구성

```
┌ 헤더: 앱 이름 · 데이터 상태(출처, 기준일) · [저장한 조건](v2) · 다크 모드 ┐
├──────────────┬───────────────────────────────────────────┤
│ 조건 패널     │ 결과                                       │
│ (왼쪽 고정폭) │  v1: 한 페이지 (카드 → 비교 표 → 그래프 → 매수 내역 → 안내) │
│              │  v2: 탭 [요약][분석][전략 비교][매수 내역]      │
└──────────────┴───────────────────────────────────────────┘
```

- 조건 패널은 왼쪽에 둔다. 조건을 바꾸면서 결과를 같이 볼 수 있다.
- v2에서 분석·전략 비교·매수 내역 탭을 열면 조건 패널을 위쪽 한 줄 요약으로 접는다. "조건 펼치기"로 다시 연다.

## v1 기능

### F-01 종목 고르기
- 종목 코드를 1~8개 넣는다. 그래프 색이 8개까지라 8개로 막는다. 패널에 "4 / 8"처럼 개수를 보여 준다.
- 넣은 종목은 줄마다 하나씩 보인다: 그래프 선 모양, 코드, 이름, 빼기(×) 버튼.
- 검색칸에 글자를 치면 Yahoo 검색으로 후보를 보여 준다 (코드, 이름, 거래소, 종류). 이미 넣은 종목은 "추가됨"으로 흐리게 보인다.
- 한국 종목은 `005930.KS`(코스피), `035720.KQ`(코스닥)처럼 넣는다. 검색은 코드(`005930`)나 영문 이름(`samsung`)으로 된다.
  - Yahoo 검색은 한글 이름을 못 찾는다 ("삼성전자" → 결과 없음, 2026-11-24 확인). 결과가 없으면 "코드나 영문 이름으로 찾아 주세요"라고 안내한다.
- 검색 후보에서 옵션·선물 같은 것은 빼고 주식, ETF, 지수, 펀드, 코인만 보여 준다.
- 종목 줄의 상태: 기본 / 받는 중 / 저장본으로 계산(기준일 표시) / 찾을 수 없음(빨간 테두리 + "종목을 찾을 수 없습니다").
  - v1은 요청 하나로 모든 종목을 계산해서, 계산 중에는 보낸 종목이 모두 "받는 중"이다 (저장본을 읽는 종목도). 받기·환율 실패처럼 다른 이유로 실패하면 "계산 못 함"이고 이유는 종목 칸 아래에 쓴다 (2026-11-25, 결정 d20).
- 색과 선 모양은 종목에 붙는다. 종목 하나를 빼도 남은 종목 색은 그대로다.

### F-02 기간
- 시작일과 끝날짜를 고른다. 기본값은 끝날짜 오늘, 시작일 5년 전 다음 날이다 (예: 2021-11-25 ~ 2026-11-24).
- 빠른 선택 버튼: 1년, 3년, 5년, 10년, 전체(상장 이후).
- 시작일이 끝날짜보다 늦으면 막는다. 끝날짜는 오늘보다 늦을 수 없다.
- 상장일이 시작일보다 늦은 종목은 상장 이후부터 계산하고, 결과 위에 "TQQQ는 2010-02-11 상장이라 그때부터 계산했습니다"처럼 알린다.

### F-03 매수 주기
- 매일 / 매주 / 매월 중 하나.
- 매주는 요일(월~금, 기본 월요일), 매월은 날짜(1~31, 기본 1일, 31은 "말일")를 고른다.
- 휴장일이면 다음 거래일에 산다. 정확한 규칙은 [계산 규칙](2_계산규칙.md) 2절. 패널에 "휴장일이면 다음 거래일. 달(주)을 넘기면 그 달(주) 마지막 거래일"이라고 적어 둔다.

### F-04 금액과 통화
- 매번 살 금액과 투자 통화(원화 / 달러)를 정한다. 기본값은 원화 200만원.
- 종목마다 매번 그 금액씩 산다. 패널에 "종목마다 매번"이라고 적어 둔다.
- 투자 통화와 종목 통화가 다르면 매수일 환율로 바꿔서 산다.
- 금액은 0보다 커야 한다. 금액 아래에 대략의 횟수와 총액을 미리 보여 준다 (예: "약 60회 · 종목당 1억 2,000만원 · 4종목 합계 4억 8,000만원").

### F-05 매수 방식 (고급 설정, 펼쳐서 고름)
- 소수점 매수(기본) / 정수 주만. 정수 주면 남는 돈은 다음 매수에 보탠다.
- 수수료(%): 기본 0. 환전 비용도 여기 합쳐서 넣는다고 안내한다.
- 접혀 있을 때도 제목 옆에 지금 값을 보여 준다 (예: "고급 설정 · 소수점 · 수수료 0%").

### F-06 결과 요약
결과 맨 위에 조건 한 줄(종목 수, 주기, 금액, 기간, 매수 횟수, 평가 기준일과 환율), 그 아래 종목마다 카드 하나, 그 아래 비교 표.

카드에 보이는 것:

| 항목 | 예 (QLD) |
|---|---|
| 평단가 (종목 통화 / 투자 통화) | $37.97 / 51,363원 |
| 수익률 / 연환산(XIRR) | +88.19% / +25.75% |
| 투자금 / 평가금 / 손익 | 1억 2,000만원 / 2억 2,582만원 / +1억 582만원 |
| 보유 수량 | 2,336.31주 |
| 현재가와 기준일 | $71.91 (2026-11-23 종가) |
| 매수 횟수와 기간 | 60회 (2021-12-01 ~ 2026-11-02) |
| 최고·최저 수익률 | +211.6% (2026-06-02) / −39.4% (2022-06-16) |
| 평가금 최고점 대비 | −34.1% (최고점 3억 4,271만원, 2026-06-02) |
| 분할 안내 | 2025-11-20 2:1 분할 반영 |

예시 값은 QLD, 매월 1일 200만원, 2021-11-25 ~ 2026-11-24 기준 실제 계산값이다.

- 원화 평단가 옆 (i)에 "매수할 때마다 그날 환율로 계산한 값. 달러 평단가 × 지금 환율과 다르다"고 알려 준다.
- 비교 표: 종목, 평단가, 원화 평단가, 보유 수량, 평가금, 손익, 수익률, XIRR, 최저 수익률, 고점 대비. 넓으면 표 안에서 가로로 민다.
- 숫자는 반올림해서 보여 준다. 금액은 원 단위, 억·만 단위 표기를 같이 쓴다.
- 손익이 +면 초록, −면 빨강. +/− 기호를 꼭 붙인다.

### F-07 그래프
1. **평가금·투자금**: 종목별 평가금 선 + 누적 투자금 회색 계단선. 일반·로그 축 전환.
2. **수익률**: 종목별 수익률(%) 선, 0% 기준선을 진하게.
3. **주가·평단가**: 종목 하나를 골라 주가 선과 평단가 회색 계단선. 주가가 평단가 위면 이익 구간.

- 마우스를 올리면 세로 기준선과 함께 그날의 값이 나온다 (날짜, 종목별 값, 투자금).
- 기간이 길어 점이 많으면 그래프에는 줄여서 그린다 (최대 약 1,000점, 첫날·마지막 날·최고·최저 수익률 날짜는 꼭 남김). 계산은 줄이지 않는다. 그래프 아래에 그렇다고 적는다.
- 범례는 색 + 선 모양(실선, 긴 점선, 짧은 점선, 점-선 …)과 마지막 값을 같이 쓴다. 색약이어도, 대비가 낮은 색이어도 구분된다.
- 다크 모드를 지원한다.

### F-08 매수 내역
- 종목을 고르면 매수할 때마다의 회차, 날짜, 종가, 환율, 산 수량, 누적 수량, 누적 평단가, 원화 평단가, 누적 투자금을 표로 보여 준다.
- 처음엔 앞 6회와 마지막 2회만 보이고 "전체 보기"로 모두 연다.
- CSV로 내려받는다 (모든 종목, 엑셀에서 한글이 깨지지 않게 UTF-8 BOM).

### F-09 조건 공유
- 조건을 주소(URL 쿼리)에 담는다. 주소를 열면 같은 조건으로 바로 계산한다.
- 결과 위 "링크 복사" 버튼으로 주소를 복사한다.
- 예: `/?s=QQQ,QLD&from=2021-11-25&to=2026-11-24&freq=monthly&day=1&amt=2000000&cur=KRW`

### F-10 안내와 오류
- 결과 아래에 고정 안내: 데이터 출처와 기준일, 분할 반영(종목과 날짜)·배당 미반영, 세금·환전 비용 미반영, 투자 권유 아님.
- 결과 위 알림 세 가지 (색 + 아이콘 + 문장):
  - 빨강: 일부 종목 실패. "QQQQ는 계산하지 못했습니다. 종목을 찾을 수 없습니다. 나머지 3개 종목 결과를 보여 줍니다."
  - 노랑: 저장본으로 계산. "QLD는 2026-11-20까지 저장된 데이터로 계산했습니다."
  - 파랑: 상장일이 늦음 (F-02).
- 입력 오류는 칸 바로 아래에 이유를 적고, 고칠 때까지 계산하기를 잠근다.
- 모든 종목이 실패하면 결과 자리에 이유와 "다시 시도" 버튼.

### v1 화면 흐름

1. 첫 화면: 왼쪽 조건 패널에 예시 조건(QQQ·QLD, 5년, 매월 1일, 200만원)이 채워져 있고, 오른쪽은 "조건을 정하고 계산하기를 누르세요".
2. "계산하기"를 누르면 버튼이 잠기고 종목별 진행(저장본 사용 / 받음 / 받는 중)을 보여 준다. 처음이면 결과 자리에 빈 틀, 다시 계산이면 이전 결과를 흐리게 둔다.
3. 결과가 나오면 주소도 같이 바뀐다. 조건을 바꾸고 다시 누르면 결과만 바뀐다.

## v2 기능

v1 위에 얹는다. v1 기능은 그대로 두고, 결과 영역을 탭으로 나눈다.

### F-11 결과 탭과 조건 패널 접기
- 결과를 탭 4개로 나눈다: **요약**(F-06·F-07·F-12), **분석**(F-14), **전략 비교**(F-15), **매수 내역**(F-16).
- 탭도 주소에 담는다 (`&tab=analysis`). 새로 고쳐도 같은 탭이 열린다.
- 요약 외의 탭에서는 조건 패널을 한 줄로 접고 "조건 펼치기"를 둔다.

### F-12 한눈에 요약
- 요약 탭 맨 위에 계산 결과로 만든 문장 한두 개와 하이라이트 4개를 보여 준다. AI가 아니라 정해진 문장 틀에 숫자를 넣는다.
  - 예: "4개 종목 모두 이익입니다. TQQQ가 수익률 +99.40%, 연환산 28.19%로 가장 높았지만 2022-06-16에는 −55.9%까지 빠졌습니다."
  - 하이라이트: 가장 높은 XIRR, 현재가가 평단가의 몇 배(최고), 가장 깊은 손실, 원금 아래였던 날이 가장 적은 종목.
- 종목 카드에 작은 수익률 그래프와 "세후 손익"(F-20), "원금 아래" 일수(F-14)를 더한다.
- 비교 표에 현재가, 세후 손익, 원금 아래 열을 더하고, 열 제목을 누르면 정렬한다. 열마다 가장 좋은 값을 굵게 한다.

### F-13 그래프 더하기
- 그래프 종류에 **낙폭**(평가금 최고점 대비, %)을 더한다.
- 범례를 누르면 그 종목을 숨기고 세로축을 남은 종목에 맞춰 다시 잡는다. 레버리지 종목 하나 때문에 나머지가 납작해지는 문제를 푼다.
- 보는 기간: 최근 1년 / 3년 / 전체. 계산은 그대로고 그리는 구간만 바뀐다.
- 평가금 그래프에서 한 종목의 최고 평가금이 다른 종목 최고의 5배를 넘으면 로그 축으로 먼저 보여 주고 이유를 한 줄 적는다.
- 주가·평단가 그래프에 주식 분할일을 세로 점선으로 표시한다.

### F-14 분석 탭
| 묶음 | 보여 주는 것 |
|---|---|
| 얼마나 흔들렸나 | 종목별 표: 최저 수익률(날짜), 평가금 최대 낙폭(날짜), 원금 아래였던 날(일수, 전체 거래일 중 %), 가장 길게 원금 아래였던 기간, 마지막으로 원금 아래였던 날. 아래에 낙폭 그래프 |
| 연도별 결과 | 연도 × 종목 표: 그해 마지막 거래일의 누적 수익률, 그해 주가 등락(작은 글씨), 그 시점 누적 투자금 |
| 달마다 얼마나 움직였나 | 종목 하나의 월별 수익률(원화) 히트맵. 오른 달/내린 달 수, 가장 크게 오른 달·내린 달 |
| 수익은 어디서 왔나 | 원화 손익 = 주가 효과 + 환율 효과. 종목별 막대와 평균 매수 환율·평가 환율 |
| 얼마에 샀나 | 매수 가격 분포 막대(12칸), 평단가 선, 지금 가격 선. "60번 중 51번은 지금 가격보다 싸게 샀습니다" |

계산 방법은 [계산 규칙](2_계산규칙.md) 9절.

### F-15 전략 비교 탭
- 조건의 종목 중 하나를 골라, 매달 같은 돈을 넣되 사는 규칙만 다른 경우를 나란히 비교한다. 전략은 종목 하나씩 계산한다.

| 전략 | 규칙 |
|---|---|
| 기본 적립 | 매번 같은 금액 |
| 이평선 아래 더, 위 덜 | 매수일 종가가 이평선 아래면 2배, 위면 절반 |
| 과열 때 절반 | 이평선보다 20% 넘게 위면 절반 |
| 레버리지 전환 | 기준 종목(기본 QQQ)이 이평선 위일 때만 산다. 아래면 현금으로 모았다가 위로 올라온 날 모아 둔 현금까지 산다 |
| 일시금 | 같은 총액을 첫 매수일에 한 번에 |

- 이평선 기간은 20 / 60 / 120 / 200일 중 고른다 (기본 200일).
- 기본 적립 외의 규칙은 **같은 예산**으로 계산한다. 넣는 돈은 매번 같고, 덜 산 돈은 현금으로 남아 평가금에 들어간다 ([계산 규칙](2_계산규칙.md) 9절).
- 전략마다 카드: 평가금, 수익률, XIRR, 평단가, 최저 수익률, 남은 현금, 규칙이 몇 번 발동했는지. 열마다 가장 좋은 값을 굵게.
- 전략별 평가금 그래프 (범례로 숨기기, 마우스를 올리면 그날 값).
- **며칠에 사면 좋았을까**: 매월 1~28일과 말일 각각의 평단가 점그래프. 지금 조건은 큰 점.
- **언제 시작했어도?**: 시작한 달을 바꿔 가며 지금까지 적립했을 때의 수익률 막대.
- 안내: 사기만 한다(파는 전략 없음). 과거에 맞은 규칙이 앞으로도 맞는다는 뜻이 아니다.

### F-16 매수 내역 탭
- F-08을 넓힌다: 종목 고르기, 연도 필터, "지금 평단가보다 싸게 산 회차만", 15줄씩 쪽 나누기.
- 열 더하기: 그날 수익률(그 매수일까지 넣은 돈 기준), 이 회차 지금(그날 산 몫만 지금 팔았을 때, 원화).
- 분할일이 지나는 자리에 안내 줄: "2025-11-20 2:1 분할. 이 위의 가격·수량은 분할 반영값입니다."
- 위에 요약(매수 횟수, 보유 수량, 평단가, 평균 매수 환율, 가장 싸게/비싸게 산 가격)과 평단가 변화 그래프(매수 가격 점, 누적 평단가 계단선, 지금 가격 점선).
- CSV 옵션 패널: 모든 종목 / 지금 종목만, 원화 평단가·누적 투자금 넣기, 날마다 평가금 넣기, 맨 위에 조건 한 줄. 파일 이름에 종목과 기간을 넣는다.

### F-17 매수 규칙 (조건 패널)
- 조건 패널에 "매수 규칙" 선택을 둔다: 기본 / 이평선 아래 2배·위 절반 / 과열 때 절반 / 레버리지 전환.
- 고르면 요약·분석·매수 내역이 모두 그 규칙으로 계산된다. 여러 규칙을 나란히 보려면 전략 비교 탭으로 안내한다.

### F-18 금액 나누기 (포트폴리오) — v2에서 제외 (2026-11-25, 결정 d37)
- 만들지 않는다. 여러 종목은 v1처럼 종목마다 매번 같은 금액을 산다.
- 시안 "v2"의 비율 관련 요소도 만들지 않는다: 조건 패널의 "종목마다 매번 / 비율로 나누기" 선택, 종목별 비율 입력과 비율 합(100%) 표시, 비율 모드의 "…을 비율대로 나눠 삽니다 · 합계 …" 미리보기, 결과의 "합계" 카드. F-04 금액 아래의 "N종목 합계" 미리보기는 그대로 둔다.
- 이유: 리밸런싱 없이 매번 금액을 비율대로 나눠 사기만 하면, 소수점 매수에서는 종목마다의 투자금·평가금·손익이 "종목마다 매번"으로 계산한 결과를 비율만큼 줄인 것과 같고, 평단가·수익률·XIRR은 그대로다 (정수 주만 살 때는 남는 돈 때문에 조금 다르다). 새로 보이는 것은 "합계" 카드 하나뿐이다. 리밸런싱까지 하는 포트폴리오는 v2 이후 후보로 둔다.
- 처음 계획: 금액 아래에서 "종목마다 매번 / 비율로 나누기"를 고른다. 비율 합이 100%가 아니면 막고, 매번 금액을 비율대로 나눠 산다. 결과에 "합계" 카드(전체 평가금, 수익률, XIRR)를 더한다.

### F-19 배당 재투자 — v2에서 제외 (2026-11-25, 결정 d36)
- 만들지 않는다. v2에서도 배당은 반영하지 않고, 결과 아래의 "배당 미반영" 안내를 그대로 둔다.
- 시안 "v2"의 고급 설정에 있는 "배당 재투자" 스위치와 조건 한 줄의 "· 배당 재투자"도 만들지 않는다.
- 이유
  - 저장한 데이터로 매월 1일 200만원 5년을 재 보면, 미국 지수·레버리지 ETF는 반영 여부의 수익률 차이가 1.5~7%p(XIRR 0.3~1.5%p)라 결론을 바꾸지 않는다.
  - 수정종가(adjclose)로 계산하면 배당소득세를 떼지 않고 전부 다시 산다고 봐서 실제보다 부풀린다.
  - 배당주는 차이가 크다(삼성전자 +16.5%p). 배당주를 많이 보게 되면 세금까지 넣은 방식으로 다시 검토한다.
- 처음 계획: 고급 설정의 스위치를 켜면 수정종가로 계산한다. 배당을 받은 날 그대로 다시 샀다고 보는 것과 같다.

### F-20 해외주식 양도세 어림
- 고급 설정의 스위치. 켜면 끝날짜에 모두 판다고 보고 `(손익 − 250만원) × 22%`를 세금으로 빼서 세후 손익을 보여 준다. 손익이 250만원 이하면 0.
- 해외 종목에만 적용한다. 한국 종목은 세금 0으로 두고 그렇다고 적는다.
- 해마다 나눠 판 경우, 다른 종목 손실과 합치는 경우는 다루지 않는다. "어림값"이라고 꼭 적는다.

### F-21 조건 저장·비교
- 결과 위 "조건 저장"으로 지금 조건에 이름을 붙여 저장한다. 이 브라우저(localStorage)에만 저장된다고 알린다.
- 헤더 "저장한 조건" 서랍: 이름, 조건 한 줄, 대표 결과(가장 높은 수익률 등). 누르면 그 조건으로 계산한다. 이름 바꾸기·지우기.
- 2개를 골라 "나란히 비교": 두 조건의 카드와 수익률 그래프를 한 화면에.

### F-22 데이터 점검 경고
- 받은 주가에서 이상해 보이는 날을 찾아 결과 위 노랑 알림으로 보여 준다. 계산은 그대로 한다.
- 찾는 규칙: 하루 등락률이 분할 비율(1/2, 1/3, 15배 등)과 거의 같은 날, 레버리지 ETF 등락이 기초 ETF × 배수와 3%p 넘게 다른 날, 종가가 비거나 같은 값이 5일 넘게 이어지는 구간.
- 같은 날 기초 ETF와 맞춰 본 결과도 같이 적는다 (예: "QLD −10.9%가 QQQ의 2배 −11.3%와 0.5%p 차이로 맞습니다").

### F-23 AI 해설
- 요약 탭 아래 카드. "해설 만들기"를 눌러야 만든다. 3~5문장.
- 넘기는 것은 계산한 요약 지표(JSON)뿐이다. 숫자는 그 안에 있는 것만 쓰고, 종목 추천과 전망은 하지 않는다.
- "AI가 쓴 해설"이라고 표시한다. 같은 조건(주소)의 해설은 저장해 두고 다시 쓴다. 하루 한도를 둔다.
- 비용과 모델은 [확장 아이디어](6_확장아이디어.md) 2-2.

### v2 화면 흐름

1. 첫 화면과 계산은 v1과 같다. 결과는 요약 탭으로 열린다.
2. 다른 탭을 누르면 조건 패널이 접히고 그 탭 내용이 나온다. 탭은 주소에 남는다.
3. 매수 규칙·세금을 바꾸면 모든 탭이 다시 계산된다. 전략 비교 탭은 규칙 설정과 상관없이 늘 5개 전략을 계산한다.

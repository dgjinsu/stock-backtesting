# 적립식 백테스트

"지난 5년간 QLD를 매달 200만원씩 샀다면 지금 평단가는?" 같은 질문에 답하는 웹 화면.
종목, 기간, 주기(매일·매주·매월), 금액을 고르면 평단가, 수익률, 평가금과 그래프를 보여 준다.

**v1(F-01~F-10)을 만들었다** (2026-11-25). 내 PC에서 켜서 쓰는 웹 화면이고, 데스크톱 브라우저용이다. 배포(8단계)와 v2 기능은 아직이다.

- 화면 시안: [Design 캔버스](https://claude.ai/artifact/Nvxz1FH9bYPKwinAibsZmr) (비공개). "v1" 페이지가 먼저 만들 화면, "v2" 페이지가 그다음 화면이다.
- 개발 현황판: [적립식 백테스트 개발 현황](https://claude.ai/artifact/4qzSDxqhz7o8zoeF2CvucF) (비공개). 단계·이슈·PR·리뷰를 이어서 기록한다.
- 결정 보드: [개발 결정 보드](https://claude.ai/artifact/JaxQyqXbXZLdmN4houmWh5) (비공개). 개발하면서 Claude가 정한 것과 사용자가 할 일.

## 실행

필요한 것: Windows, Python 3.12 이상, 인터넷 (주가를 Yahoo Finance에서 받는다).

1. 저장소 폴더의 `실행.bat`을 더블클릭한다.
   - 처음 한 번은 `.venv`를 만들고 필요한 라이브러리를 깐다 (1~2분).
   - 서버가 켜지면 브라우저가 `http://127.0.0.1:8010`을 연다. 검은 명령 창을 닫으면 서버도 꺼진다.
2. 명령으로 켜려면:

```powershell
.\.venv\Scripts\python -m src.main --open
```

환경변수로 바꿀 수 있는 것: `HOST`(기본 127.0.0.1), `PORT`(기본 8010), `DATA_DIR`(캐시 폴더, 기본 `data`. 주가는 그 아래 `prices/`에 저장).

## 사용법

처음 열면 예시 조건(QQQ·QLD, 5년, 매월 1일 200만원)이 채워져 있어 바로 **계산하기**를 누르면 된다.

1. **종목**: 검색 칸에 코드나 영문 이름을 쓰면 0.3초 뒤 목록이 나온다. ↑↓로 고르고 Enter. 목록에 없어도 코드를 그대로 쓰고 Enter를 누르면 넣는다. 한국 종목은 `005930.KS`(코스피), `035720.KQ`(코스닥)처럼. 8개까지.
2. **기간**: 시작일·끝날짜를 고르거나 1·3·5·10년·전체 버튼. "전체"는 종목마다 상장일부터.
3. **주기**: 매일·매주(요일)·매월(날짜, 말일). 휴장일이면 다음 거래일, 달(주)을 넘기면 그 달(주)의 마지막 거래일에 산다.
4. **금액**: 종목마다 매번 넣는 돈. 원화나 달러. 달러 종목을 원화로 사면 그날 환율로 바꿔 산다.
5. **고급 설정**: 소수점 매수(기본) 또는 정수 주만(남는 돈은 다음 매수에 보탬), 수수료 %(환전 비용도 여기에).
6. **계산하기**. 결과:
   - 종목 카드: 평단가, 수익률, 연환산(XIRR), 투자금·평가금·손익, 최고·최저 수익률, 평가금 최고점 대비
   - 비교 표, 그래프 3개(평가금·투자금 / 수익률 / 주가·평단가), 매수 내역
7. **공유**: 조건이 주소에 담긴다. "링크 복사"로 보낸 주소를 열면 같은 조건으로 바로 계산한다. 주소가 `127.0.0.1`이라 받는 사람 PC에서도 이 앱이 켜져 있어야 열린다 (배포는 8단계).
8. **CSV**: 결과 위 [CSV] 또는 매수 내역의 [CSV 내려받기]. 모든 종목의 매수 내역이 엑셀에서 한글이 깨지지 않게 저장된다.

## 데이터와 한계

- 주가는 Yahoo Finance의 비공식 일별 종가다. 받은 주가는 `data/prices/`에 저장하고 6시간 안에는 다시 받지 않는다. Yahoo가 실패하면 저장본으로 계산하고 노란 알림으로 알린다.
- 주식 분할은 반영한다. 배당, 세금은 반영하지 않는다 (v2에서 더한다).
- 과거 데이터로 계산한 결과이며 투자 권유가 아니다.

## 개발 환경

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python scripts\check.py
```

`scripts/check.py`는 린트(ruff), 포맷, 타입(mypy), 테스트(pytest), 웹(JS 문법과 `node --test`, Node.js 22.7 이상)을 차례로 돌린다. GitHub Actions도 PR마다 같은 스크립트를 돌린다.

## 개발을 시작할 때

1. [개발 워크플로우](docs/7_개발워크플로우.md)를 읽는다. 모든 변경은 이슈에서 시작해 PR로 들어간다.
2. 문서를 1 → 5 순서로 읽는다. 결과가 맞는지는 계산 규칙이 기준이다.
3. 1~7단계는 끝났다. 다음은 8단계(배포), 그다음 v2(9~14단계)다. 진행은 개발 현황판에서 본다.

## 테스트용 데이터

- `tests/fixtures/yahoo/`: Yahoo Finance 응답을 그대로 저장한 것 (QQQ, QLD, TQQQ, SOXL, USDKRW=X, 005930.KS, 2021-01-01 ~ 2026-11-24).
- `tests/fixtures/expected.json`: 위 데이터로 계산한 기준값. 계산 엔진은 이 값과 같아야 한다.
- `tests/reference_calc.py`: 기준값을 만든 참고 스크립트. `python tests/reference_calc.py --write`로 다시 만든다.
- `tests/test_reference_calc.py`: 참고 스크립트의 출력이 `expected.json`과 같은지 확인한다.
